# 行动计划结构

以下七个章节使用二级标题，并填写正文。没有缺失信息时，在“待确认事项”说明暂无；没有文件资料时，在“信息来源”写“用户本次消息”。

| 章节 | 内容 |
| --- | --- |
| 任务目标 | 想达成什么，以及最终交付什么 |
| 已知条件 | 用户明确给出的时间、资源和限制；额外假设单独标为建议 |
| 行动步骤 | 顺序、依赖、时间安排、具体动作、产物及完成标准；负责人未知则待确认 |
| 验收标准 | 可检查的完成条件，区分目标和实际结果 |
| 风险与调整 | 可能阻碍、触发调整的条件、缩减或调整方案 |
| 待确认事项 | 需要用户补充的条件，不替用户编造答案 |
| 信息来源 | 用户本次消息及实际读取过的文件准确路径 |

学习任务可以按理解、练习、复盘拆解；开发任务可以按范围、实现、验证拆解；活动任务可以按筹备、执行、复盘拆解。这些仅为建议，不强制所有任务使用同一套阶段。
