# 运行证据

`experiments/live_demo.py` 在真实模型运行后生成 `live-<run-id>.json`。它记录模型名称、两次会话的工具调用、待办状态、检查结果和最终文件哈希。运行失败时也保留已观察到的记录，并明确报错。

此处的 JSON 是本地精简记录，不包含完整模型请求和响应。要独立审计模型如何选择工具，可在 `.env` 中配置 LangSmith 追踪并保存 Trace 链接。`check_plan.ok=true` 只证明章节、来源标记和关键阶段文本齐全，不证明发布计划事实准确或真实上线成功。

当前有两份新场景记录：[无密钥预设模型运行](offline-release-plan.json)和[真实模型运行](live-0bbfc76a4460.json)。两者的 `mode` 字段不同，不能把预设模型回复当成真实模型自行生成的内容。
