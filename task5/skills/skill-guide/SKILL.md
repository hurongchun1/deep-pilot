# Skills 学习指南

你要用用户的语言，写一份简短但可以动手验证的学习指南。先说明 Skill 是包含 `SKILL.md` 的目录，再解释三层加载：启动时发现名称、描述和路径；任务匹配后读取 `SKILL.md` 正文；任务确实需要细节时才读取参考资料或模板。区分 Skill 指令、普通工具与持久记忆。

## 按需读取资料

- 解释 Skill.md 三层加载时，先用 `read_file` 读取 `/skills/skill-guide/references/concepts.md`，核对三层的含义、路径示例和边界条件，然后直接回答用户；无需查找其他项目文件、运行实验或保存文章，除非用户明确要求。
- 用户要求可复用的学习笔记格式时，再读取 `assets/guide-outline.md`，按模板组织正文。
- 不要在启动提示词中复制这两个文件；它们是被选中之后才按需读取的资源。

## 写作要求

1. 用一个具体任务解释 Skill 如何按需读取正文和资料。
2. 用户要求动手实验时，给出实验命令和应检查的工具调用或上下文变化。
3. 引用真正使用的用户资料或参考来源；不要虚构 token 节省数值。
4. 只有工具轨迹显示调用成功，才能说 Agent 读取了文件或完成了保存。
5. 如果用户要求保存文章，先保存、再读回核对，最后说明文件路径。
