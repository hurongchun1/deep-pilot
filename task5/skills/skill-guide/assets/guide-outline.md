# 学习笔记模板

这份模板用于把章节概念写成可复现的实验记录。请填入实际命令和观察结果，不要把预期结果当成已经发生的事实。

## 一、问题与场景

写出用户要完成的具体任务，以及为什么只调用一次工具还不够。例如：写 Skills 学习笔记，需要查阅术语、组织正文、保存文件并读回核对。

## 二、Skill 结构

列出 `SKILL.md`、`references/`、`assets/` 各自放什么内容。摘录一条具体的 `description`，说明它会匹配什么请求。

## 三、三层加载观察

| 轮次 | 预期可见内容 | 实际观察 |
| --- | --- | --- |
| 首轮 | Skill 名称、描述、路径 | 填写提示词或轨迹中的证据 |
| 读取正文后 | `SKILL.md` 指令 | 填写 `read_file` 返回内容或提示词证据 |
| 读取资源后 | 所需参考资料或模板 | 填写资源文件名和出现时机 |

## 四、动手实验

从 `task5` 目录运行：

```powershell
uv run --frozen python experiments/ch07_progressive_disclosure.py
```

核对四轮中文输出和最后的 `PASS`。该离线实验预设工具调用，只验证图和文件加载机制；想检验真实模型能否自行挑选 Skill，需要另外查看真实模型的工具轨迹。

## 五、结论与易错点

写出本次观察能够支持的结论，并检查三个常见错误：`description` 过于笼统、把单个文件当成 Skill 父目录、把资源误认为启动时已经加载。
