## 一条主线

先定义任务与完成标准，再决定要提供哪些工具、文件、记忆和 Skill；多步骤任务可加入规划，敏感操作加人工审核，最终产物用独立证据验收。模型负责提出动作和生成候选，应用负责边界、存储和放行。

## 证据口径

- **离线机制实验**：预设模型下一步要调用什么，但运行真实 Agent 图、工具和 Backend；适合验证框架机制，不能证明真实模型会自主选择同一路径。
- **真实模型实验**：观察真实调用轨迹与产物；能证明该次运行发生了什么，不能保证之后每次都一样。
- **结构检查**：只检查格式和章节；不能据此断言内容正确、方案可行。

多数课程实验锁定 `deepagents==0.7.8`。API、默认中间件和参数可能随版本变化；以后迁移时先核对当前官方文档和依赖锁文件，再复现实验。笔记中的“本项目”均指 `deep-pilot` 仓库。

## 推荐的复习方法

1. 先读 `01` 和 `10`，建立总图。
2. 遇到具体问题时只打开对应主题，回答文末的“自测问题”。
3. 对照每篇的“项目证据”去看实验记录和代码；遇到版本差异时重新运行最小实验。
4. 新发现按“问题 → 预测 → 实际证据 → 结论与边界”追加到相应主题，而不是只保存聊天记录。
